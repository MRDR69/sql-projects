## 📊 Sales Analysis — SQL Project
### 📌 Overview

This project analyzes sales data to identify key business trends, customer behavior and product performance.

The objective is to use SQL to transform raw sales data into actionable business insights.

### 🎯 Business Questions

The analysis will answer the following questions:

### Sales Performance

- What is the total revenue?
- How many orders were placed?
- What is the average order value?
- How does revenue evolve over time?

### Product Performance

- Which products generate the most revenue?
- Which categories perform best?
- Which products have the highest sales volume?

### Customer Analysis

- Which customers generate the most revenue?
- How many orders does each customer place?
- What is the average customer order value?

### Regional Analysis

- Which regions generate the most revenue?
- How does sales performance differ between regions?

### Advanced Analysis

- What percentage of total revenue does each product represent?
- What are the monthly sales trends?
- Which products are growing or declining over time?
